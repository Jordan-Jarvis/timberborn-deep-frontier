# Deep Frontier mod

The mod as the official Timberborn Mod Builder packages it (see the repository README for the build).

- `manifest.json`: mod id `DeepFrontier`, version, minimum game version and required mods.
- `Scripts/`: the main `DeepFrontier` assembly (`DeepFrontierModStarter` applies the Harmony patches; Bindito configurators register each feature). `Scripts/RadioactiveTide/ModdableWeathers` and `Scripts/SluiceIsBack` build optional assemblies that load only when Moddable Weathers or Sluice is Back! is enabled.
- `Data/`: blueprints, recipes, goods, needs, localization, meshes and sprites. Most blueprints are generated by `tools/*_content.mjs`; edit the generators, not the generated JSON.
- `AssetBundles/`: material and mesh sources packaged into the asset bundle.
- `Editor/`: Unity editor helpers used by the build (material authoring).
- `Art/`: source art (Blender scenes in Git LFS, concepts, icons, textures); not packaged.
