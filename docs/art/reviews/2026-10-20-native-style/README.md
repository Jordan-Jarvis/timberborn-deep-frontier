# Native material and housing-rail review

Iron Teeth materials follow REDIC New Building Styles. Deck rails reuse the original Folktails Double Lodge posts and handrails, including UVs. These are Blender renders; native validation is recorded in STATUS.

21 detailed building variants use the shared style pass. The remaining catalog entries below are older prototypes and are not presented as finished concept-quality buildings.
